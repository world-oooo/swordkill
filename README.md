# The Last Light — Legend of the Wooden Sword

> 꺼져가는 마지막 빛을 들고, **허접한 나무검 한 자루**로 마왕성까지 나아가는
> 2D 탑다운 로그라이크 액션 게임. (Soul Knight의 구도·시스템을 참고한 **오리지널 게임**)

🎮 **지금 바로 플레이**: https://swordkill.vercel.app
💻 **소스 코드**: https://github.com/world-oooo/swordkill
🛠 **엔진**: Godot 4.6.3 (GDScript)

## 📖 스토리

천 년 동안 세상을 지켜온 빛이 꺼져간다. 마지막 빛을 손에 쥔 주인공은,
가진 것이라곤 **낡은 나무검** 하나뿐. 변경의 숲에서 마왕성까지 —
각 지역의 수호 보스를 쓰러뜨리고 더 강한 검을 얻어, 마침내 **어둠의 군주**와
맞서는 것이 목표다.

| **G** | 바닥의 보상 줍기 |

## ⚔️ 핵심 시스템

### 방 & 통로 (소울나이트식)
- 격자로 연결된 방들을 **통로(문)** 로 이동. 이동 시 화면이 부드럽게 페이드.
- **전투방에 들어가면 문이 잠기고**(전투 중 못 나감) 적이 등장 → **전멸 시 문이 열림**.
- 카메라가 방 경계에 고정되어 방에 집중되는 연출.
- 방 종류: 시작 거점 · 전투 · 정예 · 보물 · 상점/대장간 · 보스.
- 미니맵으로 방 그래프와 진행 상황 확인. 떠났다 돌아와도 바닥 아이템/상점이 유지됨.

### 전투 손맛
- **검기(slash) 이펙트** — 검마다 고유한 검기가 베는 방향으로 휘날림.
- **콤보** — 적을 연속으로 베면 콤보 누적(위에 남은시간 바), 일정 시간 안 때리면 초기화.
- **크리티컬** — 확률로 1.5배 데미지(노란 큰 숫자 + 데미지 표시).
- **타격감** — 피격 시 적이 빨갛게 번쩍, 넉백, 화면 흔들림, 히트스톱(순간 정지감).

### 검 / 무기 (인벤토리에서 장착)
허접한 나무검부터 시작해 보스를 잡을수록 강해진다:
| 검 | 설명 |
|----|------|
| 허접한 나무검 | 시작 무기 |
| 녹슨 철검 | |
| 기사단의 강철검 | |
| 룬이 깃든 마검 | 룬이 빛나는 애니메이션 |
| 용살의 화염검 | |
| 빛의 성검 「에이렌」 | 최종 무기 |

> 그 외 **서리검·뇌명검** 등 속성검은 고유한 이미지 검기를 가짐.

### 대장간 / 강화 & 상점
- **대장간(거점)**: 모은 재화로 능력치·검을 강화.
- **상점방**: 코인으로 무기, 젬으로 최대 HP·실드·에너지 영구 강화.
- **재화**: 코인(적 처치·상자), 젬(보스·보물).

### 캐릭터 스탯
- **HP / 실드 / 에너지** 3종 게이지.
- **패시브**: 실드가 깨지는 순간 짧은 피해 면역.
- HUD에 게이지·재화·미니맵·콤보·보스 체력바 표시.

### 스테이지 & 보스
| 스테이지 | 보스 | 보상 검 |
|----------|------|---------|
| 변경의 숲 | 오크킹 | 강철검 |
| 폐허의 마을 | 레이븐 | 빛 검 |
| 저주받은 늪 | 늪지대 마녀 | 룬 마검 |
| 마왕성 | 어둠의 군주(최종) | 성검 |

- 보스는 추적 + 원형 탄막 등 패턴 공격. **최종 보스는 페이즈별로 강해지며** 대사가 나온다.

## 🚀 직접 실행 / 빌드

### 에디터에서 실행
1. Godot 4.6.3으로 `project.godot` 열기
2. **F5** 로 실행 (시작 씬: `Intro.tscn`)

### 웹(HTML5) 빌드
1. 에디터 → 내보내기 템플릿 설치
2. 프로젝트 → 내보내기 → **웹** 프리셋 → `build/web/index.html` 로 내보내기
3. 정적 호스팅(Vercel 등)에 `build/web` 폴더 업로드

> 이 저장소의 게임은 **Vercel**로 배포되어 있습니다: https://swordkill.vercel.app

## 🗂 프로젝트 구조 (요약)

```
soul-knight-clone/
├── project.godot          # 메인 씬 = Intro
├── scripts/               # game_manager, player, room, door, weapon, enemy, boss,
│                          #   hud, inventory, forge_ui, slash_effect, ...
├── scenes/                # Intro / Lobby / Main / Room / Inventory / 적·보스 · 무기 · UI
└── assets/                # backgrounds(스테이지 배경) / enemies / equipment / sword /
                           #   ui / fonts  (아트는 AI 생성 오리지널 에셋)
```

- **게임 흐름**: 인트로 → 로비 → 방 그래프 진행(전투/상점/보물) → 보스 → 다음 스테이지 → 최종 보스 → 결과.
- **GameManager**(오토로드)가 진행·재화·콤보·맵·보스 상태를 총괄.

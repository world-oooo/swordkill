# 주인공 스프라이트 넣는 법

여기(`assets/player/`)에 **본인이 만들었거나 CC0/라이선스 프리** 스프라이트를 넣어주세요.
(소울나이트 원본 그림은 저작권 문제로 사용할 수 없습니다 — 오리지널/프리 에셋만.)

## 권장 사양
- **픽셀아트**, **배경 투명(PNG)**, 캐릭터는 **오른쪽을 바라보게** (왼쪽은 코드가 자동으로 뒤집습니다).
- 캐릭터 발이 대략 그림 하단 중앙에 오도록.

## 두 가지 방식 중 하나로 주세요

### 방식 A — 가로 스프라이트 시트 1장 (권장)
- 한 줄에 같은 크기의 프레임이 가로로 나열된 PNG.
- 예: `player_walk.png` (걷기 6프레임), `player_idle.png` (대기 2~4프레임)
- 알려줄 것: **프레임 한 칸의 가로/세로 픽셀**, **걷기 프레임 수**, **대기 프레임 수**

### 방식 B — 프레임별 낱장 PNG
- 파일명 규칙으로 주세요:
  - 대기: `idle_0.png`, `idle_1.png`, ...
  - 걷기: `walk_0.png`, `walk_1.png`, ...

## 넣은 뒤
파일을 이 폴더에 두고 위 정보(프레임 크기·개수)를 알려주시면,
`Body` 노드 아래에 `AnimatedSprite2D`로 연결하고 `idle`/`walk` 애니메이션을 만들어
이동 시 자동 전환되도록 코드에 물리겠습니다. (현재의 홉/스쿼시 효과는 그 위에 그대로 유지됩니다.)

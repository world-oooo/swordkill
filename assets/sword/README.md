# 검(Sword) 이미지 넣는 곳

주인공이 드는 **검 한 자루** 이미지를 여기(`assets/sword/`)에 넣어주세요.
(직접 만든/CC0·프리 에셋만. 이 게임은 검 1종만 사용합니다.)

## 권장 사양
- **픽셀아트, 배경 투명(PNG)** (단색 흰/회색 배경도 가능 — 자동 제거)
- **검이 오른쪽(→)을 향하도록** 그려주세요. 손잡이(hilt)가 **왼쪽 끝**, 칼끝이 **오른쪽 끝**.
  - 이렇게 해야 손잡이를 기준으로 휘두르는 애니메이션이 자연스럽습니다.
- 프레임은 **1장(정지 이미지)** 이면 됩니다. (휘두르는 동작은 코드가 회전으로 만듭니다)

## 넣은 뒤
파일을 이 폴더에 두고 알려주시면:
1. 흰 배경이 있으면 제거(`assets/tools/process_sprite.py ... --frames 1 --no-label-strip`)
2. 무기의 `Blade`를 **Sprite2D(검 텍스처)**로 교체하고, 휘두르기 애니메이션(회전)을 연결합니다.

> 현재는 임시 회색 막대 검으로 동작 중 — 이미지를 주시면 그 그림으로 바꿉니다.
